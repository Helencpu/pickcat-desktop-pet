# 🐱 PICKCAT 网页小桌宠（浏览器插件）

一只来自 [pickcat.dao3.fun](https://pickcat.dao3.fun/) 的小猫桌宠，浮动显示在你浏览的任意网页上。

## ✨ 功能
- **拎起来 + 物理倾斜**：鼠标按住桌宠即可拖动，拖动时会按速度向运动方向实时倾斜（往右拖向右倾、往左拖向左倾，越快倾角越大，慢下来会回正）
- **放下来 + 重力**：松手即释放。桌宠会被**重力**拉着加速下落，触地**弹跳几次**后稳稳落在地面（带轻微落地压扁）
- **压扁 + 声音**：单击桌宠，会先水平拉宽、垂直压扁，再带弹性地弹回；同时发出小黄鸭被按压的“吱~吱~”声（用 Web Audio 实时合成，无需额外音频文件，请打开网页声音）
- **透明底**：桌宠已把官方 favicon 的白色背景抠成透明，无白色方块，仅保留跟随形状的柔和投影，在任意网页上都不突兀

## 📁 文件说明
| 文件 | 作用 |
|------|------|
| `manifest.json` | 插件清单（Manifest V3） |
| `content.js` | 注入到网页的核心逻辑（拖拽、压扁动效、鸭子声音合成） |
| `pet.png` | 桌宠形象（pickcat.dao3.fun 的 favicon，已抠成透明底） |
| `preview.html` | 独立预览页，双击即可在浏览器直接体验，无需安装插件 |
| `make_transparent.py` | 抠图脚本（用边缘泛洪去掉白色背景，可自行调整阈值重跑） |

## 🛠 安装到浏览器（Chrome / Edge / 任何 Chromium 浏览器）
1. 打开浏览器，在地址栏输入并进入扩展页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角（或左侧）的 **“开发者模式”** 开关。
3. 点击 **“加载已解压的扩展程序”**，选择本文件夹 `pickpet`（包含 manifest.json 的那一层）。
4. 安装后桌宠会出现在当前网页右下角，刷新任意页面即可看到。

## 🖱 使用方法
- **按住拖动** = 拎起来，放到喜欢的位置；**松手** = 放下。
- **单击** = 压扁动效 + 小黄鸭吱吱声。
- 桌宠默认出现在**右下角**，每次刷新网页会回到默认位置（如需记住位置，可自行扩展）。

## 🔧 常见调整
- **大小**：打开 `content.js`，修改顶部 `PET_SIZE`（默认 72，单位 px）。
- **重力**：`content.js` 顶部 `GRAVITY`（加速度，默认 2400，越大下落越快）、`BOUNCE`（弹跳系数，0~1，越小落地弹得越低）、`FLOOR_GAP`（落地离底部的间距）。
- **倾斜**：`content.js` 顶部 `TILT_K`（倾斜灵敏度，默认 0.055）、`MAX_TILT`（最大倾斜角，默认 26°）。
- **默认位置**：`content.js` 中 `px`/`py` 的初始值（默认右下角）。
- **音量/音色**：修改 `content.js` 中 `playDuck()` 里的 `0.28`（主音量）和振荡器频率即可。
- **重新抠图**：改 `make_transparent.py` 里的白色阈值（默认 `> 240`）后重跑，重新生成透明底 `pet.png`。

## ✅ 说明
- 使用 Chrome Extension Manifest V3，全网页生效（`<all_urls>`）。
- 图片直接复用 PICKCAT 官方 favicon（`/favicon.png`），安装包自带，不依赖外网。
